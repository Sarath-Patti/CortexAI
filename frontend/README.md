# CortexAI Frontend Service

React 18 + TypeScript + Vite + Tailwind CSS application foundation.

## Structure
- `src/api`: Modular API client architecture.
- `src/components`: Reusable UI components and layouts.
- `src/pages`: Page views and views routes.
- `src/router`: React Router setup.
- `src/types`: TypeScript type definitions.

## Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```
